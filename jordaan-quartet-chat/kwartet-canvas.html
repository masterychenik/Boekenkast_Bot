Jordaan Kwartet — geanimeerde chat op canvas

Live modus — chat met echte SLM's via Ollama (bijv. iPad → Mac opzelfde Wi-Fi)
Model per personage:

Op je Mac (zelfde Wi-Fi): ollama pull mistral en OLLAMA_HOST=0.0.0.0 OLLAMA_ORIGINS=* ollama serve. Let op: dit zet een onbeveiligde API open op je Wi-Fi — alleen op een vertrouwd thuisnetwerk. Standaard luistert Ollama alleen op 127.0.0.1. Werkt file:// niet? Serveer de map op je Mac: python3 -m http.server 8000 en open op de iPad http://<mac-ip>:8000/jordaan-quartet-chat/kwartet-canvas.html.

Eigen chat laden: python3 quartet_chat.py --topic "..." --export chat.json (met Ollama), laad daarna chat.json via de knop hierboven.
